# Проект: Юнит-тестирование BooksCollector

## Описание
Тесты для класса `BooksCollector`, который управляет книгами, их жанрами и избранным.

## Список тестов

### Тесты для метода `add_new_book`
1. **`test_add_new_book_success`** — проверяет, что книга успешно добавляется в словарь.
2. **`test_add_new_book_duplicate`** — проверяет, что дубликат книги не добавляется.
3. **`test_add_new_book_max_length`** — проверяет, что книга с названием > 40 символов не добавляется.
4. **`test_add_new_book_empty_name`** — проверяет, что книга с пустым названием не добавляется.

### Тесты для метода `get_book_genre`
5. **`test_get_book_genre`** — проверяет, что метод возвращает жанр книги по её имени.

### Тест для метода `get_books_with_specific_genre`
6. **`test_get_books_with_specific_genre`** — проверяет, что метод возвращает список книг с определённым жанром.

### Тест для метода `get_books_for_children`
7. **`test_get_books_for_children`** — проверяет, что метод возвращает только книги без возрастного рейтинга.

### Тесты для работы с избранным
8. **`test_add_book_in_favorites`** — проверяет, что книга добавляется в избранное.
9. **`test_delete_book_from_favorites`** — проверяет, что книга удаляется из избранного.
10. **`test_add_book_in_favorites_not_in_books`** — проверяет, что книга, отсутствующая в словаре, не добавляется в избранное.

### Дополнительный тест (из заготовки)
11. **`test_add_new_book_add_two_books`** — проверяет добавление двух книг (пример из заготовки).

## Запуск тестов
Для запуска всех тестов выполните в терминале команду:

python -m pytest -v tests.py


Для запуска конкретного теста выполните в терминале команду:

python -m pytest -v tests.py::TestBooksCollector::имя_теста


## Покрытие методов
- `add_new_book` — 4 теста
- `get_book_genre` — 1 тест
- `get_books_with_specific_genre` — 1 тест
- `get_books_for_children` — 1 тест
- `add_book_in_favorites` — 2 теста
- `delete_book_from_favorites` — 1 тест
- `get_list_of_favorites_books` — используется в тестах для избранного
- `set_book_genre` — используется в тестах (покрывается через другие тесты)
- `get_books_genre` — используется в тестах (покрывается через другие тесты)

**Все методы класса покрыты тестами.**
